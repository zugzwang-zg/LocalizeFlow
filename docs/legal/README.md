# Legal and privacy document map

Last updated: 2026-08-15

This folder separates active project policy from blocked hosted-service drafts.
It is release engineering documentation, not legal advice.

## Active operational policy

- `MODEL_DATA_POLICY.md`: requires no training or provider improvement using
  user material and blocks model processing when provider facts are unverified.
- `LEGAL_RELEASE_CHECKLIST.md`: records completed preview safeguards and the
  unresolved gates for any hosted trial.

The active public-preview documents are at the repository root:
`PRIVACY.md`, `TERMS.md`, `ACCEPTABLE_USE_POLICY.md`, and `DISCLAIMER.md`.

## Blocked templates — not active

- `HOSTED_TRIAL_PRIVACY_DRAFT.md`
- `HOSTED_TRIAL_TERMS_DRAFT.md`
- `MODEL_PROVIDER_DISCLOSURE_TEMPLATE.md`

These files intentionally contain `[REQUIRED]` markers. They must not be
presented as active policies or user assurances. A hosted trial remains closed
until verified production facts replace every marker and the completed
documents receive appropriate review.
