# 人工计时替换说明

当前分析使用 AI 情景估算，84.4% 不是人工实测结果。本说明用于未来获得专业人士后替换估算值。

请打开 `data/measurements/business_value_measurements.xlsx`，进入 `Manual Timing` 工作表。

依次完成表中的 6 个任务：

1. US / en-US / 商品 Listing
2. US / en-US / 15 秒短视频脚本
3. US / en-US / 社媒广告文案
4. MX / es-MX / 商品 Listing
5. MX / es-MX / 15 秒短视频脚本
6. MX / es-MX / 社媒广告文案

## 计时规则

- 使用 `MV-SERUM-001` 的同一份商品事实。
- 不查看或复制 LocalizeFlow/Baseline 候选文案。
- `Manual Start` 填写开始时间，`Manual End` 填写自检结束时间。
- 计时包含撰写、英西语调整、平台结构调整和自检。
- 休息或中断不计时，并在 `Notes` 中说明。
- 六项最好由同一位执行者连续完成。
- 如果使用词典、机器翻译或其他工具，在 `Notes` 中如实记录。

填写完成并保存工作簿后，可用实际时间替换 AI 情景估算，并将证据等级升级为人工实测。
