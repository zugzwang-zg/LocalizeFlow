# LocalizeFlow 2 分 25 秒演示视频讲解稿

> 视频文件：`demo/LocalizeFlow_Demo.mp4`
> 画面：8 页项目概览幻灯片，每页 18 秒，片头与片尾淡入淡出
> 音轨：静音 AAC 音轨，便于后续录制真人旁白或替换配音
> 当前版本无需 API。若后续使用在线 AI 配音服务，需要先配置相应 API 或服务账号。

## 00:00–00:18｜项目定位

LocalizeFlow 不是一个只把中文翻译成英文或西班牙文的工具。它把商品事实、消费者洞察、品牌语言和平台规则放进同一条可追溯工作流，重点解决跨境内容生成后的事实风险和复核成本。当前原型覆盖五个虚拟 SKU、美国和墨西哥两个市场，并且无需 API 即可本地演示。

## 00:18–00:36｜用户与场景

目标用户是需要同时处理商品资料、多语言表达和平台格式的跨境内容运营。典型任务从选择商品和市场开始，系统生成三类内容并显示事实来源，运营人员完成质量检查、人工修订和终审后才能导出。产品边界是交付带证据的候选稿，不负责自动发布，也不替代专业审核。

## 00:36–00:54｜商品事实库

项目先把五个商品拆成结构化事实，而不是让模型直接阅读一整段产品说明。每条事实保存来源、证据等级、适用市场和生成门控。以精华为例，容量、配方和允许宣称都有明确边界，而“不黏腻”因为缺少产品测试会被阻断。每条内容声明都能追到 `fact_id` 和来源。

## 00:54–01:12｜消费者洞察

消费者洞察是一种语言与策略资源，而不是产品证据。项目人工通读了五十条英语和五十条西语评论，但源数据没有评论者国家，因此只作为内容语言代理。洞察分为 eligible、strategy only 和 blocked 三类；没有商品事实支持的偏好不能被写成产品功效。

## 01:12–01:30｜七节点工作流

核心工作流拆成七个单一职责节点，从事实加载、策略选择、本地化、内容生成，到事实核验、规则检查和质量评分。高风险事实错误或平台硬规则失败会直接阻断。人工修改后必须创建新版本并重新检查，最终仍由人工批准。

## 01:30–01:48｜产品 Demo

Demo 包含商品资料、营销任务、生成结果、质量检查和版本导出五个页面。演示时可以选择商品和市场，一次查看 Listing、短视频和社媒内容，定位事实和语言问题；人工修改并复检通过后，才开放 CSV 和 JSON。当前采用冻结内容和确定性模板，以保证本地可复现。

## 01:48–02:06｜评测与业务价值

评测包含三十组 A/B、六十条匿名候选。LocalizeFlow 的七维总体均分从二点七八提高到四点二，修改次数减少百分之六十一点五，审核时间减少百分之二十五点八，事实通过率提升二十六点七个百分点。同时，代表性 SKU 的事实错误率仍为百分之三十三点三，主要与包装字段有关。

## 02:06–02:25｜局限与下一步

当前样本规模小、只有一位评审者，消费者洞察也没有国家字段，在线模型的延迟和成本尚未测试。下一步会先补强包装事实字段和多评审评测，然后在配置 API 后记录真实模型调用。任何密钥都只进入本地环境变量，不写入代码、文档或截图。

## 录制建议

- 真人旁白按本稿正常语速录制，目标时长控制在 2 分 15 秒至 2 分 25 秒；
- 每页在画面切换后停顿约半秒，再开始对应讲解；
- 第 6 页可暂停视频，切换到本地 Streamlit 做一次实时操作，再返回视频；
- 如果使用 AI 配音，先确认服务授权、声音许可和 API 配置，并重新检查最终音画时长。
