# Streamlit Demo 操作说明

## 演示定位

这个 Demo 把 LocalizeFlow 的核心链路压缩成一条可现场操作和复现的流程：

> 选择商品 → 设置市场与平台 → 生成内容包 → 查看质量检查 → 人工修改与确认 → 导出

当前版本为离线、确定性演示。它读取项目内已经冻结的商品事实、评测内容和规则，不调用模型 API，不代表真实平台批准或法务结论。

## 启动

在项目根目录执行：

```powershell
.\.venv\Scripts\python.exe -m streamlit run app\main.py
```

然后打开 `http://localhost:8501`。

## 五个页面

1. **商品资料**：选择 5 个虚拟 SKU 之一，查看结构化事实及 `fact_id`，核对允许/禁止表达，并可上传或粘贴补充资料。
2. **营销任务**：选择美国或墨西哥市场、目标用户、营销目标、平台/内容类型、核心卖点与品牌语调。目标语言随市场锁定。
3. **生成结果**：一次生成商品 Listing、TikTok 脚本与通用社媒文案；每项事实声明旁显示来源 ID。
4. **质量检查**：检查事实边界、包装、结构、字符限制、术语、品牌一致性和本地化表现。事实失败会阻断导出。
5. **版本与导出**：并列比较 Baseline 与 LocalizeFlow 增强版；人工修改后自动复检，勾选终审确认后开放 JSON/CSV。

## 推荐演示脚本

1. 保持默认商品 `MV-SERUM-001`。
2. 选择美国市场与商品 Listing，确认输出语言是 `en-US`。
3. 点击“生成本地化内容包”，查看三个内容标签及事实来源。
4. 进入质量检查，观察 `a opaque → an opaque` 术语/语言提示。
5. 在最终编辑器中把 `a opaque` 改为 `an opaque`。
6. 勾选人工终审确认，点击“确认最终版本”。
7. 确认“下载 JSON”和“下载 CSV”按钮出现。

若要演示阻断逻辑，可选择手霜样本并保留已知包装矛盾；修订包装描述并重新检查后，阻断可被解除。

## 设计与边界

- 界面采用“证据驱动的本地化编辑台”风格，深墨绿、纸张底色和琥珀色强调共同区分事实、警告与操作。
- 页面是真正的五步导航，不是单页长表单；会话状态保留当前商品、任务、内容包、人工修订和确认结果。
- 新上传或粘贴的资料只保存在当前会话，不会直接改写冻结事实库。
- 导出文件保留任务元数据、版本、质量检查、人工确认和事实来源，便于演示与复盘。
