## Incident and support channels

- Public Demo or documentation problem: use the repository's Support request or
  Bug report issue form. Never include customer content, secrets, personal data,
  or unpublished product information.
- Security vulnerability or suspected data exposure: follow `SECURITY.md` and
  use GitHub Private Vulnerability Reporting. Do not create a public issue.
- Hosted privacy requests: no channel is active because no hosted trial is
  active. A dedicated request channel remains a release blocker.

If an incident affects the public preview, the maintainer will update a pinned
GitHub issue and this file when practical. A future hosted trial must replace
this manual process with a public status surface fed by independent probes.
