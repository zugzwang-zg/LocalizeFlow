## 使用提示

- PPT 已包含逐页演讲者备注，可直接用于 2–3 分钟项目陈述；
- 视频使用静音 AAC 音轨，适合后续录制真人旁白；
- 当前离线 Demo 不需要 API；
- 若接入在线模型或 AI 配音，先配置本地 `.env` 或对应服务账号，不要把密钥写入公开文件；
- `84.4%` 是 AI 时间估算得到的情景结果，不是人工实测，不能表述为已验证的效率提升。
