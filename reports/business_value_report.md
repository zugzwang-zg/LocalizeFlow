# LocalizeFlow 业务价值报告

> 状态：情景估算版。质量、复核效率和系统耗时来自实际记录；完整生产时间与 84.4% 节省率来自 AI 情景估算，非人工实测。

## 1. 测量范围

- SKU：`MV-SERUM-001`
- 市场与语言：美国英语（US / en-US）、墨西哥西语（MX / es-MX）
- 内容类型：商品 Listing、15 秒短视频脚本、通用社媒广告文案
- 同一版本任务单元：2 个市场 × 3 种内容类型 = 6 个输出
- A/B 评测记录：Baseline 与 LocalizeFlow 各 6 条，共 12 条候选
- 系统计时：每个市场 30 次，共 60 次市场调用；每次调用同时组装 3 个内容输出
- 数据日期：2026-07-28

原始记录位于：

- `data/measurements/serum_evaluation_records.csv`
- `data/measurements/serum_evaluation_records.json`
- `data/measurements/system_timing_benchmark.csv`
- `data/measurements/system_timing_benchmark.json`

LocalizeFlow 的事实错误率没有下降，原因是英美和墨西哥西语两个 Listing 都包含未获当时事实参考支持的包装材质信息。这一结果与失败案例分析一致，已保留为系统不应隐藏的失败模式。

## 3. 系统生成时间与成本

当前 Demo 使用冻结内容与确定性模板，不调用模型 API。因此：

- 模型推理时间：不适用
- 模型 API 调用：0 次
- 模型 API 费用：0 元
- 美国市场 3 个输出的本地组装中位时间：0.403850 毫秒（n=30）
- 墨西哥市场 3 个输出的本地组装中位时间：0.466050 毫秒（n=30）
- 两个市场 6 个输出的配对中位时间：0.863350 毫秒（n=30）

上述时间只衡量本机确定性内容包组装，不包含在线模型推理、网络延迟、真实平台请求、人工审核或发布操作，不能用于推算未来在线模型的速度与成本。

## 4. 完整生产时间节省情景

采用的 AI 情景估算如下：

| 市场 | 内容类型 | AI 估算分钟 |
|---|---|---:|
| US / en-US | 商品 Listing | 35 |
| US / en-US | 15 秒短视频脚本 | 25 |
| US / en-US | 社媒广告文案 | 18 |
| MX / es-MX | 商品 Listing | 45 |
| MX / es-MX | 15 秒短视频脚本 | 32 |
| MX / es-MX | 社媒广告文案 | 24 |
| **合计** | **6 项输出** | **179** |

情景计算公式：

```text
完整生产时间节省率
= 1 -（LocalizeFlow 系统组装时间 + LocalizeFlow 人工复核时间）
      / 纯人工完成同一 6 项任务的总时间
```

LocalizeFlow 六项候选的实际盲评复核时间合计为 28 分钟；两个市场内容包的本地组装中位时间合计约 0.863350 毫秒，即约 0.000014 分钟。

```text
情景时间节省率
= 1 -（28 + 0.000014）/ 179
= 84.4%
```

84.4% 只能表述为“基于 AI 时间估算的情景结果”，不能表述为“实测节省 84.4%”。如果未来获得专业人士的现场计时，应直接替换 `Manual Timing` 中的估算分钟数并重新计算。

## 5. 人工与系统任务范围对齐

AI 估算采用的任务范围与系统任务保持一致：

1. 使用同一 SKU 和同一份商品事实。
2. 分别完成 US/en-US 与 MX/es-MX。
3. 每个市场完成 Listing、短视频脚本和社媒文案。
4. 内容结构遵循同一平台规则。
5. 计时包含撰写、语言调整、结构调整和自检，不包含休息。
6. 估算假设执行者不使用 LocalizeFlow 或生成式 AI；墨西哥西语任务可查阅常规词典与平台规范。

## 6. 不适用或高风险场景

- 商品事实缺失、来源冲突或包装材质未经核实。
- 医疗、临床、认证、药品或其他需要专业合规判断的声明。
- 目标市场术语和文化表达尚未进入规则库的新语言或新品类。
- 依赖实时价格、库存、促销或平台政策的内容。
- 需要直接发布、投放或代表真实平台审批的场景。
- 需要高度原创品牌创意、长期品牌策略或母语级细微语用判断的任务。

LocalizeFlow 在这些场景中只能作为草稿和预检工具，不能替代法务、平台、品类专家与目标语言人工终审。

## 7. 测量限制

- 仅测试 1 个虚拟 SKU、2 个市场和 3 种内容类型。
- 每个版本只有 6 条同 SKU 候选，样本量很小。
- 盲评工作簿只有一位评审人的记录，无法计算评审者间一致性。
- 修改次数来自盲评记录，不是上线产品的行为埋点。
- 平台通过率是本地规则预检结果，不是 Google、TikTok 或真实社媒平台批准率。
- 术语一致率只覆盖当前小型规则集已编码的问题。
- 当前为离线确定性 Demo，API 成本为 0 不代表未来在线模型成本。
- 179 分钟由 AI 估算，不是专业人士或目标语言从业者的现场记录。
- 84.4% 混合了 AI 估算的纯人工时间和实际记录的复核/系统时间，只能作为情景分析。
- 该情景值不能表述为“已验证效率提升”；可验证结果应优先引用实际记录的 20.0% 复核时间降幅和 55.0% 修改次数降幅。
